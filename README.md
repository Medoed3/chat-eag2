# Корпоративный мессенджер с гарантированной доставкой

## Архитектура Store-and-Forward

Система переработана для обеспечения 100% надежности доставки сообщений с помощью архитектуры "Store-and-Forward".

### Основные компоненты:

1. **Redis** - для управления соединениями, Pub/Sub уведомлений, кэширования и очередей
2. **SQLite** - основное хранилище сообщений (с расширенной схемой)
3. **FastAPI** - REST API для синхронизации и подтверждений
4. **WebSocket** - только для lightweight уведомлений

## Установка и запуск

### Способ: Без Docker

```bash
# Клонируйте проект
git clone <репозиторий>

# 4. Установите Python зависимости
cd backend
pip install -r requirements.txt

# 5. Запустите приложение
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# Или используйте скрипт запуска (из корня проекта):
python run_local.py
